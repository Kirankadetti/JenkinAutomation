# \# PipelineX — Jenkins CI/CD Automation

# 

# \## DevOps Internship — Task 2

# 

# A simple CI/CD automation project using Jenkins, Docker, Node.js, and Jest.

# 

# \## Project Overview

# 

# PipelineX demonstrates an automated CI/CD workflow where source code is checked out from GitHub, dependencies are installed, automated tests are executed, a Docker image is built, and the application is deployed as a Docker container.

#

#

# \- Node.js

# \- Express.js

# \- Jest

# \- Supertest

# \- Git

# \- GitHub

# 

# \## Pipeline Stages

# 

# 1\. \*\*Checkout\*\* — Retrieves source code from GitHub.

# 2\. \*\*Build\*\* — Installs project dependencies.

# 3\. \*\*Test\*\* — Runs automated Jest tests.

# 4\. \*\*Docker Build\*\* — Creates the application Docker image.

# 5\. \*\*Deploy\*\* — Runs the application inside a Docker container.
